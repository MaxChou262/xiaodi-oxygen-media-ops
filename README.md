# 小狄氧舱自媒体平台运营智能体

给氧舱经销商用的自媒体运营智能体。经销商说一句话，拿走 10 条这周就能拍的脚本——
装在一个排版好的 HTML 文件里，手机上能看，打印出来能带到现场。

```
@小狄氧舱自媒体平台运营智能体 杭州 GYCHA-M001 本周同城和全国康养热点，出10个能拍的
```

---

## 它解决什么

经销商自己开号，卡在三个地方：

1. **不知道拍什么。** 康养类内容看着都差不多，拍两条就没词了。
2. **热点蹭不上。** 知道本地有话题，但不知道跟自己卖的东西有什么关系。
3. **不敢说。** 抄公司资料里的功效话术，发出去就是违规。

这个 Skill 把三件事接成一条线：**取热点 → 挂到产品上 → 出可拍的稿 → 过合规 → 去 AI 味**。
中间不需要经销商懂营销、懂参数、懂平台。

### 方式一：WorkBuddy（推荐）

把整个 `xiaodi-oxygen-media-ops/` 放进 `~/.workbuddy/skills/`，然后：

```
@小狄氧舱自媒体平台运营智能体 杭州 GYCHA-M001 本周同城和全国康养热点，出10个能拍的
```

### 方式二：Claude / Gemini / 各类支持提示词的客户端

直接粘 `prompts/runtime-prompt.md` 的全部内容，效果接近但不带文件读写（周快照、经销商档案用不了）。

### 方式三：只想看输出长什么样

- `examples/02-sample.html` —— **实际交付物长这样**。双击用浏览器打开，手机上也能看。
- `examples/01-hangzhou-week47.md` —— 同一批内容的原文（Markdown 源，供比对）。
- `docs/使用教程.pdf` —— 给经销商看的使用手册，四页，可直接转发。

热点都是虚构的示例数据，标了「示例」。

## 使用规则

### 输入只要三个

| 输入 | 说明 |
|---|---|
| 城市 | 必填。本地热点是这套东西唯一的差异化，不给就出不来 |
| 型号 | GYCHA-S001 单人／GYCHA-M001 双人／GYCHA-M002 四人／GYCHC-M001 四人 |
| 需求 | 默认「本周热点＋10 条脚本」，不说也行 |

### 输出是一个 HTML 文件

文件名 `小狄氧舱-<城市>-<型号>-<YYYYMMDD>.html`，单文件自包含，断网能开。文件内部分五段：

1. **顶栏** 城市／型号／日期／热点层级（L1 实时／L2 快照／L3 季节）
2. **本周热点** 3–5 条，标来源与可挂到第几条
3. **10 张脚本卡** 每条六项：标题／热点挂点／口播（20–25 秒，带秒数与字数）／3 个镜头／拍摄耗时／CTA
4. **拍摄顺序** 哪 3 条一次拍完
5. **页脚** 合规声明 ＋ 「要哪条出完整版，说编号」

对话框里只回三句：文件路径、一句热点说明、一句下一步。**不重复脚本内容。**

没有文件读写能力的环境（网页版对话框等）会退成 HTML 代码块让你存盘；纯文本环境退成 Markdown，并在开头说明。

### 二次指令

| 你说 | 它做 |
|---|---|
| 展开第 3 条 | 出完整分镜版（分镜表／字幕／发布包／素材出处／合规自检） |
| 换一批 | 保配比换角度 |
| 这条太平了 | 只改钩子和前 3 秒 |
| 拍不了 | 给零素材替代版 |
| 这句话能说吗 | 逐句对照改写 |
| 上周播放 300、完播 9% | 一句话诊断 ＋ 三条动作 ＋ 下一条拍什么 |

### 六条铁律

1. 一次只展开一条完整脚本（10 条完整分镜没人看，也会被截断）
2. 每条标拍摄耗时，超 40 分钟写「这条本周别拍」
3. 先问能拍到什么，再定选题（素材决定选题，不是反过来）
4. 不写拍不了的东西，不用「可以找网图」糊过去
5. 经销商不是营销从业者，不对他说「B 端」「决策人」「G3 组」这类词
6. HTML 不许引外链（字体、图标、CDN），也不许在对话框里贴全文

## 设计原理

### 1 热点为什么不是内置的

热点每天变。任何随仓库分发的热点文件，打包那一刻就开始过期。
真做成「实时统计全国所有城市的热点」，需要一个常开的爬虫服务——那不是 Skill，那是一个产品。

所以这里用**三层兜底**，并且强制标注用了哪一层：

| 层 | 条件 | 标注 |
|---|---|---|
| L1 实时检索 | 默认 | 「热点取自实时检索，截至 YYYY-MM-DD」 |
| L2 周快照 | 检索不可用 | 「实时未取到，基于 YYYY-MM-DD 快照」 |
| L3 季节常青 | 前两层都空 | 「未取到实时热点，以下为季节选题」 |

**标注不是免责，是让经销商自己判断。** 他发出去的东西挂了「昨天热搜」，客户会去搜。

### 2 为什么要先挂桥，再写稿

不是所有热点都能用。只留五类能一句话搭上桥的：
公共健康政策／生活方式／生意与消费／科学与争议／本地事件。

10 条里挂上 6 条热点是正常的。硬蹭 10 条，评论区第一条就拆穿。

四维打分（相关 0.4／本地 0.25／时效 0.2／安全 0.15）取前十，
**安全性一票否决**：灾难、医疗事故、明星、对立、涉政，再热也不用。

### 3 为什么是 10 条简版，不是 10 条完整

10 条完整分镜约 800 行，经销商不会看，模型也会被截断。
简版卡里已经有口播全文和三个镜头——**本来就是能开拍的**，只是没写时间码和字幕卡。

20–25 秒也是刻意的：短稿念得下来，一次能拍三条，冷启动账号完播率也高。
要长版说「展开第 N 条」，出 45–60 秒的完整版。

### 4 为什么型号要进角度

经销商分不清参数，但分得清「四人舱讲翻台、单人舱讲私密」。

| 型号 | 讲什么 |
|---|---|
| 单人 | 一个人的一小时 |
| 双人 | 两个人一起躺（关系，不是情侣） |
| 四人 | 一次四个人，一天几轮 |
| 改造型 | 一个房间能改成什么样 |

用错型号讲错角度，是经销商最容易露怯、也最容易被同行看出来的地方。

### 5 去 AI 味为什么放在口播里

文章靠「结构破坏」去味，口播靠「断句和具体物」去味。
AI 写的中文有个共同特征：句子长度均匀、逻辑连接完整。文章里这叫工整，念出来这叫念稿。

所以规则只有六条：句长必须参差、铲五类僵尸词、删 60% 显性连词、数字口语化、
每段必须有一个具体物、允许「说白了」这类口头插入。
判据也只有一条：**念一遍，像在读稿就是没过。**

`scripts/deai_check.py` 能自动查前五条（句长方差、禁用词、标点、连词、时长），查不出「念着别扭」。

### 6 合规为什么比公司口径更严

经销商账号不在上市公司口径管理范围内。说错话，责任落在他自己身上，也会反噬品牌。

所以内置的红线比对外宣讲更保守：疗效词、绝对化、收益承诺一律不用；
讲原理必带「它不是药，不治病，也不替代医疗」；
涉及医院必带「医用 2.0–3.0 ATA／家用 ≤1.3 ATA，不是一个量级」。

### 7 为什么交付是 HTML，不是聊天记录

经销商不会在对话框里照着念稿。他会把手机放在舱盖上，一边调压一边看；
或者打印一张纸塞在口袋里。这两件事聊天记录都做不到。

HTML 单文件同时解决三件：
**手机上排版不塌**（单列、15px 起、行高 1.8）、**打印不切卡**（A4 一页两张，`break-inside:avoid`）、
**口播能一键复制**（点按钮粘进提词器，手选必漏字）。

红线的取舍也在这里：**样式内联、零外链**。经销商在店里开热点看文件，一断网，
外链字体会掉成宋体、图标会变方块——那比丑更糟，会让他觉得这东西不能用。

样式只有一份真源：`references/60-html-output.md`。改版式改那一处，示例和产出都跟着变。

## 两个小脚本

```bash
# 热点打分：候选 JSON/CSV → 排名前 10
python scripts/hotspot_score.py candidates.json

# 口播自检：句长方差、禁用词、标点、时长、AI 味评分
python scripts/deai_check.py 口播.txt
```

零依赖，Python 3.8+。

## 维护与贡献

### 每周快照（社区共建）

任何人跑完一次实时检索，都可以往 `data/hotspots/` 提交一份 `YYYY-Www.md`。
它不保证新鲜，只保证「总比没有强」。格式见 `_TEMPLATE.md`。

### 适合贡献什么

- 新的热点源（尤其是地方性媒体、行业垂类号）
- 新的桥句（把某类热点挂到氧舱上的一句话）
- 本地化词库（城市商圈、地标、方言词）
- 新的病灶改法（真实账号数据里发现的失败模式）

### 不适合贡献什么

- 具体客户的案例、名字、业绩（隐私与合规风险）
- 承诺收益的话术（违反合规底线）
- 「保证上热门」这类运营承诺

## 局限（先说清楚）

1. **它不知道经销商的真实素材。** 会给镜头清单，拍不了的会直接说拍不了，不会拿空话填。
2. **它不判断本地客群。** 城市人口结构、商圈属性只能给通用逻辑。
3. **热点可能过期。** 用之前看一眼输出里的数据层级标注。
4. **合规责任仍在发布者。** 这个 Skill 降低风险，不承担法律责任。正式投放前建议走公司口径审核。
