# 热点源清单与检索模板

> 这里是给 L1（实时检索）用的。不是数据本身——数据每天变，检索方法不变。

## 全国级

| 源 | 怎么用 | 备注 |
|---|---|---|
| 抖音热榜 | 搜「抖音热榜 今日」 | 最贴近短视频受众，优先 |
| 微博热搜 | 搜「微博热搜 今日」 | 社会议题多，注意安全性过滤 |
| 百度热搜 / 指数 | 搜「百度热搜 今日」 | 政策类、健康类偏多 |
| 知乎热榜 | 搜「知乎热榜」 | 争议类好用（抗衰、智商税） |
| 头条热榜 | 搜「头条热榜」 | 中老年受众，跟氧舱客群重叠 |
| 小红书热点 | 搜「小红书 热门话题 健康」 | 女性、康养、月子中心 |

## 本地级（必须带城市名）

```
<城市> 养生
<城市> 康养 政策
<城市> 健身房 / 中医 / 体检 / 月子中心
<城市> 马拉松 / 展会 / 新店开业
<城市> 天气 预警
```

> 本地事件的价值在于「同城推荐池小」：一条本地赛事或极端天气，比一条全国热搜更容易吃到同城流量。

## 检索纪律

1. **6–9 次就停。** 查多了模型开始堆素材。
2. **只留 14 天内。**
3. **安全性一票否决**：灾难、医疗事故、明星、对立、涉政，一律不用。
4. **取不到就写取不到。** 编造热点是最严重的错误。
