# 热点引擎：三层数据 + 五类挂桥 + 四维打分

## 为什么不能内置一份"全国热点库"

热点是每天变的。任何随仓库分发的静态热点文件，打包那一刻就开始过期；
真做成"实时统计全国所有城市"，需要一个持续爬取的爬虫服务和一台常开的服务器——那不是 Skill，那是一个产品。

所以这里的做法是**三层兜底**：能实时就实时，不能实时就用最近快照，再不行用季节规律，
并且**必须告诉经销商用的是哪一层**。

| 层 | 触发条件 | 数据新鲜度 | 输出标注 |
|---|---|---|---|
| L1 实时检索 | 默认 | 当天 | 热点取自实时检索，截至 YYYY-MM-DD |
| L2 周快照 | 检索工具不可用／离线 | 最近 7 天 | 实时未取到，基于 YYYY-MM-DD 快照 |
| L3 季节常青 | 前两层都空 | 无时效性 | 未取到实时热点，以下为季节选题 |

**标注不是免责，是让经销商自己判断。** 他发出去的东西挂了"昨天热搜"，他的客户会去搜。

## L1 实时检索：查什么、查几次

### 检索预算：6–9 次，查完就停

不是查得越多越好。超过 9 次，模型开始把搜索结果当素材堆砌，反而失真。

### 全国级（2–3 次）

```
今日热搜榜 抖音
今日热搜 微博 健康
康养 银发经济 最新 报道
```

### 垂类（2–3 次，挑与氧舱有关的）

```
睡眠经济 最新 数据
体重管理年 进展
健身房 闭店 最新
月子中心 行业 变化
中医夜市 火爆
高压氧 研究 最新
抗衰 智商税 争议
```

### 本地级（2–3 次，必须带城市名）

```
<城市> 养生
<城市> 康养 政策
<城市> 健身房 / 中医 / 体检 / 月子中心
<城市> 马拉松 / 展会 / 新店开业
<城市> 天气 预警（极端天气是天然的健康话题切入口）
```

### 时效过滤

只留 **近 14 天**。超过 14 天的写"旧闻"，不要挂热点名义。

### 我取不到时怎么办

不要编。直接走 L2，并在第一行写明。**编造热点是这套东西最严重的错误，比不给热点严重得多。**

## 五类挂桥：热点凭什么能挂到氧舱上

只有能一句话说通的才留。说不通就丢——硬蹭的热点，评论区第一条就会拆穿。

| 类别 | 典型热点 | 桥在哪（一句话） |
|---|---|---|
| 1 公共健康政策 | 体重管理年、慢病防控、全民健身、控烟控酒 | 政策把"日常健康管理"推成公共话题，氧舱是其中一个可预约的动作 |
| 2 生活方式 | 熬夜、久坐、睡眠不足、通勤、屏幕疲劳、应酬 | 讲的不是病，是"累"，氧舱给的是"一小时没人找你" |
| 3 生意与消费 | 实体店难做、会所转型、银发经济、月子中心、健身房闭店 | 空房间的坪效问题，是这些老板每天在算的账 |
| 4 科学与争议 | 高压氧研究、抗衰是不是智商税、补剂争议 | 争议本身就是流量，主动划清"医用/家用"反而涨信任 |
| 5 本地事件 | 本地新店、赛事、展会、极端天气、流感高发 | 同城流量池小，一条本地事件能吃到同城推荐 |

### 桥句库（直接用，别自己造）

```
「<热点>上了热搜，我只问一句：<与老板相关的问题>」
「<热点>我不评价，但它暴露了一件事：<与时间/空间/人力相关的事实>」
「<热点>之后，很多人问我<一个问题>。我不辩解，带你看<一个具体的地方>」
「<城市>这两天<天气/事件>，这种时候最该做的是<一个动作>」
```

## 四维打分：从 20 条候选里挑 10 条

每个候选热点打 1–5 分，加权求总分，取前十。脚本能算（`scripts/hotspot_score.py`）。

| 维度 | 权重 | 5 分长什么样 | 1 分长什么样 |
|---|---|---|---|
| 相关性 | 0.40 | 一句话就能挂到氧舱，且不牵强 | 要绕三个弯才扯得上 |
| 本地性 | 0.25 | 就在这个城市，同城能看到 | 纯全国抽象话题 |
| 时效性 | 0.20 | 48 小时内 | 一个月前 |
| 安全性 | 0.15 | 无医疗暗示、无对立、无灾难 | 需要解释才不违规 |

**安全性是一票否决，不打分。** 碰到下面这些直接丢，不管多热：

- 灾难、事故、伤亡、疾病个案（尤其"某某猝死""某地中毒"）
- 医疗纠纷、医美事故、保健品打假（会被连带）
- 明星塌房、绯闻、去世
- 性别对立、地域对立、阶层对立
- 涉政、涉宗教、涉民族
- 未证实的传闻、谣言边缘

理由：经销商账号是实名露脸的本地生意。蹭一次灾难，等于把店挂在上面。

## L2 周快照：谁跑谁写

格式见 `data/hotspots/_TEMPLATE.md`。规则三条：

1. 文件名 `YYYY-Www.md`（如 `2026-W47.md`），一周一份，覆盖不追加
2. 只记**热点标题＋来源＋一句挂桥**，不记全文，控制在一屏
3. 谁用谁更新。跑完 L1 顺手写一份，下一个人就有 L2 可用

这个目录是**社区共建**的：任何人跑完一次检索，都可以提交一份快照 PR。
它不保证新鲜，只保证"总比没有强"。

## L3 季节常青表（按月，取不到热点时用）

| 月份 | 常青主题 | 可挂的角度 |
|---|---|---|
| 1–2 月 | 年末加班、春节应酬、返乡、体检季前 | 应酬后的恢复、年后开工状态 |
| 3–4 月 | 换季、过敏、春困、健身旺季启动 | 换季身体反应、春季计划 |
| 5–6 月 | 减重季、露肤季、高考、梅雨/回南天 | 体重管理、湿气、考前状态 |
| 7–8 月 | 高温、暑期亲子、旅游、空调病 | 高温下的体力、亲子同行、冷气房 |
| 9–10 月 | 开学、秋乏、马拉松季、国庆出行 | 秋乏、赛事恢复、长途后调节 |
| 11–12 月 | 流感季、年末冲刺、雾霾、跨年 | 流感季防护（不承诺防病）、年末疲惫 |

**用 L3 时必须写明"未取到实时热点"。** 把常青选题包装成热点，是最容易被同行看穿的一种假。

## 一页速查

```
取数：L1 搜 6–9 次（全国2-3 / 垂类2-3 / 本地2-3）→ 失败走 L2 快照 → 再失败走 L3 季节
过滤：14 天内；安全性一票否决
挂桥：五类；一句话说不通就丢；桥句从库里选
打分：相关0.4 本地0.25 时效0.2 安全0.15 → 取前 10
标注：必须写明用了哪一层、截至哪天
```
