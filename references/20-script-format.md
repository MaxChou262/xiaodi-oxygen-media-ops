# 脚本格式：先给简版，按需给完整版

经销商要的是"能拍"，不是"能读"。所以默认交付简版卡——**卡里有口播全文和三个镜头，本来就能开拍**。
完整分镜版按需展开，一次一条。

---

## 一、简版脚本卡（默认交付物）

每条 10 行以内，六项固定：

```markdown
**03｜你最贵的成本不是房租**
- 热点挂点：本地「实体店难做」讨论 ＋ 全国「空置商业面积」话题 → 空房间的坪效
- 口播（22 秒／105 字）：
  你最贵的成本不是房租。是这个房间，周一到周五，上午十点到下午两点。
  你已经在付它了。房租、暖气、前台、折旧，一分没少。唯一没定的，是这四个小时它挣不挣钱。
  氧舱不用人守着，它要的是排期。六十分钟一次，像项目一样被预约，不占你一个人力。
- 镜头：① 你站在空房间里说第一句（近景）② 摇镜扫空场地（全景）③ 舱门打开＋控制屏亮起（特写）
- 拍摄耗时 15 分钟｜难度 ★
- CTA：你店里最闲的是哪几个小时？打在评论区。
```

**规则：**

- 标题 ≤12 字。超过 12 字念不完、字幕放不下。
- 口播 20–25 秒，85–120 字，分 3 段。段落即镜头，1 段对 1 镜。
  短是刻意的：20 秒的稿他一眼能看完、念得下来、一次能拍三条。要长版说"展开第 N 条"。
- 镜头写"你店里怎么拍"，不写"空镜""B-roll"这种行话。
- 拍摄耗时按真实估：3 个镜头 × 走位 + 重录 ≈ 15 分钟。要客户出镜的另算半天。

## 二、10 条的类型配比

| 类型 | 条数 | 作用 | 例 |
|---|---|---|---|
| 算账类 | 2 | 让老板算得出账 | 空房间成本、一天几轮 |
| 避坑类 | 2 | 建立专业权威 | 断电容不容易看出来、报告怎么看 |
| 体验/场景类 | 3 | 让客人想象得到 | 一小时的私密、双人周末、团体预约 |
| 厂家与信任类 | 2 | 解决"跟你做行不行" | 售后排期、上市公司的检测能力 |
| 本地热点借势 | 1 | 吃同城流量 | 本地赛事、天气、新店 |

**至少 3 条反常识**：主动劝退、主动划清医用与家用、主动说一个城市只做一个。
B 端账号里反着说话的人少，这是最稳的停留来源。

## 三、完整分镜版（二次指令「展开第 N 条」才出）

八块，一块不少：

```markdown
## NN｜标题

> 时长 62 秒｜口播 291 字｜9 段｜形式 F1＋B-roll
> 剪辑 22–26 cut/min｜拍摄耗时 25 分钟｜热点来源：<哪条，哪天>

### 分镜表
| 镜号 | 时间码 | 画面 | 景别 | 口播 | 字幕/大字卡 |

### 口播全文
（提词器直接念，不省略）

### 字幕与大字卡
关键词高亮／全屏卡 N 处／只用一种强调色

### 拍摄清单
按场景归并，标"必须实拍／可动画替代／没有就别拍"

### 发布包
3 个标题（落差／数字／反常识）＋5–8 标签＋置顶评论＋平台改法

### 素材出处
哪句话用到哪个参数／案例，一句交代

### 合规自检
勾选清单（见 40-facts-compliance.md）
```

## 四、工艺参数

| 项 | 值 |
|---|---|
| 语速 | 4.7 字/秒（≈280 字/分钟） |
| 30 秒 | 140 字，4–5 段，6–9 镜 |
| 45 秒 | 210 字，6–7 段，10–14 镜 |
| 60 秒 | 280 字，8 段，14–18 镜 |
| 90 秒 | 420 字，11–12 段，18–24 镜 |
| 气口 | 7–9 秒一段，超 12 秒必拆 |
| 剪辑节奏 | 慢 4–17／中 22–26／快 30+ cut/min |
| 钩子 | 第 1 句就是结论，身份放第 2 句或删 |

**写完先数字数。** 说到 60 秒就要 280 字，不要写完 450 字再让剪辑砍——砍完逻辑就断了。

## 五、前 3 秒的三种合法写法

| 写法 | 例 | 适用 |
|---|---|---|
| 结论前置 | 「你最贵的成本不是房租。」 | 算账类 |
| 主动劝退 | 「我劝你先别买舱。」 | 反常识 |
| 划清界限 | 「医院那台和店里这台，不是一个东西。」 | 信任类 |

反例：「大家好，我是做了多年健康行业的 XX」——观众不关心你是谁，关心你说的对他有没有用。

## 六、CTA 对照

| 弱 | 强 |
|---|---|
| 私信我了解详情 | 你在哪个城市、手上什么场地，打在评论区 |
| 欢迎咨询合作 | 先聊半小时，不谈钱 |
| 关注我了解更多 | 下一条讲 XX，想接着听的点个关注 |
| 有兴趣可以联系 | 你昨天刷到几点？报个时间 |

门槛必须低到「打一行字」，且答案对经销商有筛选价值（城市、场地、客群）。

## 七、常见病灶

| 症状 | 改法 |
|---|---|
| 标题平 | 塞身份落差或两个数字 |
| 前 3 秒报身份 | 结论提到第 1 句，名字后置或删 |
| 论证跳步 | 补对比物：中小厂 vs 上市公司、家用 vs 整机 |
| 参数堆砌 | 一条只讲一个参数 |
| 结尾软 | 换成让观众报一个具体信息 |
| 太长 | 拆成两条，或砍到一件事 |
| C 端腔调 | 「家人们」一律删，用「你」或直接陈述 |
