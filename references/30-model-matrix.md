# 型号矩阵：同一个热点，四个型号要讲四件事

经销商最容易露怯的地方，是拿四人舱讲"一个人的私密时光"，或者拿单人舱讲翻台率。
型号决定买家是谁，买家决定选题角度。这一页就是防止这件事。

---

## 一、四个型号

| 型号 | 舱型 | 典型买家 | 一句话卖点 |
|---|---|---|---|
| GYCHA-S001 | 单人（2500×1000×1800mm） | 美容院、理疗馆、工作室、小型门店 | 一个人的一小时，不被打扰 |
| GYCHA-M001 | 双人 | 夫妻店、亲子、闺蜜场景、社区店 | 两个人一起躺，关系型消费 |
| GYCHA-M002 | 四人 | 会所、健身房、酒店、康养中心 | 一次四个人，一天几轮 |
| GYCHC-M001 | 四人（改造型） | 机构、独栋场地、别墅会所 | 一个房间能改成什么样 |

> 参数以 `40-facts-compliance.md` 为准。型号只决定**角度**，不决定参数口径。

---

## 二、四个型号 × 四类选题

### GYCHA-S001 单人

| 选题类型 | 怎么讲 | 镜头要点 |
|---|---|---|
| 体验 | 一小时的私密：手机留在门外，没人找你 | 关门、隔离感、舱内视角 |
| 算账 | 一个房间、一台机器、一天能排几场 | 预约本、计时器 |
| 避坑 | 单人舱最容易买错的是尺寸和进出方式 | 舱门开合、坐姿全身 |
| 场景 | 谁最适合单人舱：一个人来的客人占比多少 | 前台登记、单人客人背影 |

**不能讲**：翻台率、团体预约、双人套餐。讲了客人会问"那我带老公来怎么办"，你答不上来。

### GYCHA-M001 双人

| 选题类型 | 怎么讲 | 镜头要点 |
|---|---|---|
| 体验 | 两个人一起躺，各躺各的，不用说话 | 双人舱内视角、两人并排 |
| 场景 | 夫妻、母女、闺蜜——关系型消费比单人客单价高 | 两人进舱、门口换鞋 |
| 算账 | 双人场次的时间成本没变，收入变了 | 排期表上"双人"标注 |
| 信任 | 双人舱对空间要求更高，这是门槛 | 场地尺寸、装修收口 |

**最好用的一条**：双人舱是"关系场景"，不是"情侣舱"。把亲子、母女、闺蜜都算进去，客群宽一倍。

### GYCHA-M002 四人

| 选题类型 | 怎么讲 | 镜头要点 |
|---|---|---|
| 算账 | 一次四个人，一天三轮＝十二人次 | 四人舱全景、四人进出 |
| 场景 | 团体预约：团建、家庭、运动队、员工福利 | 更衣区、等候区 |
| 避坑 | 四人舱最容易低估的是场地承重和进出动线 | 门槛、通道宽度 |
| 信任 | 机构采购看的是使用率和留存，不是参数 | 机构场地外景、使用登记 |

**不能讲**：一个人的私密时光。四人舱讲私密，等于告诉客户"我这台卖不出去"。

### GYCHC-M001 四人（改造型）

| 选题类型 | 怎么讲 | 镜头要点 |
|---|---|---|
| 案例 | 一个房间改成氧舱间，要动哪三样：电、地面、通风 | 改造前后对比 |
| 算账 | 改造投入是一次性的，坪效是长期的 | 平面图、动线示意 |
| 避坑 | 改造最常见的错：先买舱再改房，顺序反了 | 施工过程、预留口 |
| 信任 | 改造型对厂家配合度要求最高，这是筛选供应商的题 | 上门勘测、施工交底 |

**这条线最容易出爆款**：改造前后对比的画面对比度极强，是同城流量里最吃的类型。

## 三、型号写错的三种典型

| 错误 | 现场表现 | 后果 |
|---|---|---|
| 四人舱讲个人体验 | 视频里一个人躺四人舱，画面空一半 | 观众第一反应是"这舱卖不动" |
| 单人舱讲翻台 | 说"一天能排六场"，但单人客单价撑不住 | 算出来的账一算就穿 |
| 双人舱当情侣舱 | 只有情侣画面 | 客群砍半，亲子母女客全丢 |

---

## 四、一句话记法

```
单人 → 一个人的一小时
双人 → 两个人一起躺（关系，不是情侣）
四人 → 一次四个人，一天几轮
改造 → 一个房间能改成什么样
```

写稿前先默念这一行，角度基本不会错。
