# 去 AI 味：口播专用六条

> 蒸馏自 deai-promax（五层爆破 + 24 模式）。原文是给文章和小说用的，口播只需要其中一部分——
> 文章靠"结构破坏"去味，口播靠"断句和具体物"去味。这里只留对 30–60 秒口播有效的，删掉不适用的。

---

## 为什么口播更容易露 AI

AI 写的中文有个共同特征：**句子长度均匀、逻辑连接完整、每句都在"展开"**。
文章里这叫工整，念出来这叫念稿。人对"念稿"的容忍度极低——三句话听不出来就划走了。

所以口播去 AI 味的目标不是"像人写的"，是**"像人说的"**。

---

## 六条，每条都要过

### 1 句长必须参差

一段里要有 5–8 字的短句，也要有一个 20 字以上的长句。全段等长＝像机器。

```
✗ 氧舱能够通过提高环境压力来增加血液中的溶解氧含量，从而改善身体的供氧状态。
✓ 压力上去，血里的溶解氧就多了。这跟吃药不一样——药是作用在你身上，这个只是把环境改了。
```

### 2 铲掉五类僵尸词

| 类别 | 禁用 | 换成 |
|---|---|---|
| 公文动词 | 进行、开展、实施、落实、推进 | 直接说动作：量、试、排、拆 |
| 商业黑话 | 赋能、助力、打造、构建、闭环、生态、抓手、链路 | 删掉，或说人话：帮你卖、教你拍 |
| 空泛修饰 | 全方位、一站式、精准、深度、高效、专业团队 | 给具体：三个镜头、四十分钟 |
| 转折套话 | 值得注意的是、不难发现、众所周知、综上、总而言之 | 直接说结论 |
| 排比壳 | 不是 A 而是 B（特别是三连"不是X，不是Y，只是Z"） | 只留 B，A 删掉 |

> **「不是 A 而是 B」是中文 AI 的第一特征。** 十篇里有八篇在用。一条口播里最多出现一次，
> 而且 A 必须是观众真的会以为的答案，否则就是自问自答的废话。

### 3 删 60% 显性连词

首先、其次、最后、因此、然而、此外、同时、另外——这些词在纸上帮你，在嘴上害你。

```
✗ 首先，氧舱不是什么新东西。其次，医用和家用不是一个量级。因此，你不用担心安全问题。
✓ 氧舱不新，医院用了几十年。但你店里那台跟医院那台，不是一个东西。
```

### 4 数字口语化

| 书面 | 口语 |
|---|---|
| 30% | 三成 |
| 2023 年 | 前年 / 去年 |
| 60 分钟 | 一个小时 |
| 2500×1000×1800mm | 一个电话亭那么大 |
| ≤30kPa | 比大气压高一点点（专业场合再说数字） |

数字只在"必须让观众记住"的时候才念全。其他时候说人话。

### 5 每段必须有一个具体物

没有具体物的段落，一律重写。具体物只有四种：

- 一个参数（24V、49 分贝、六十分钟）
- 一份文件（检测报告、认证证书）
- 一个现场细节（门槛高度、换鞋、手机放门外）
- 一个真实案例（哪个场地、什么形态）

```
✗ 我们的产品在安全性上做了很多工作，用户可以放心使用。
✓ 舱里是 24 伏，不是 220。断电会自动泄压，还有一声报警。
```

### 6 允许不完美

人可以有的东西，AI 很少有：口头插入、半句停顿、自我修正。

- 口头插入：「说白了」「讲实话」「你可能会问」「我一开始也不信」
- 停顿：用破折号或句号断一下，别一句话到底
- 自我修正：「表面看是贵——不，贵不是问题，是没人来。」

一条口播里放 1–2 处就够，放多了变成装的。

## 自检（写完念一遍，五条）

1. **念得出来吗？** 有一句念着别扭，就是没过。
2. **最短的句子有几个字？** 全段没短于 8 字的句子 → 重写。
3. **有没有具体物？** 三段里至少两段要有参数/文件/细节/案例。
4. **禁用词扫一遍**：进行、赋能、打造、全方位、一站式、闭环、值得注意、首先/其次/因此。
5. **数一下「不是……而是……」**：超过一次，删到一次。

脚本能跑自动检查：

```bash
python scripts/deai_check.py 口播.txt
```

输出：句长方差、禁用词命中、破折号/冒号密度、显性连词密度、AI 味评分（0–100，越低越好）。

## 不改动清单（防误杀）

下面这些**不是** AI 特征，别为了"去味"把好句子改坏：

- 短句多——口播本来就该短
- 问句多——B 端内容靠提问推进
- 反复出现同一个词（如"舱"）——口语就是会重复，同义替换反而假
- 比喻——比喻是人类特征，AI 反而少用
- "你"字开头的句子——口播必须用第二人称
- 数字精确（24V、49 分贝）——精确是可信度来源，不要口语化成"差不多"

**去 AI 味不是把话说糙，是把话说短、说具体、说得像在跟一个人讲话。**
